# Changelog

## 2.4.6

- 将页面、托盘、状态提示、临时模式和应用规则中的节能档位名称统一为 `Eco`；内部继续使用 `Quiet` 枚举，以兼容既有配置、遥测、迁移和回滚数据。
- 手动选择 Eco 时强制内屏固定 60 Hz，并显式关闭 HDR/Advanced Color；退出 Eco 时恢复已捕获的显示状态。
- Eco 继续锁定现有 Ryzen AI 9 365 离电曲线：CPU 65/60/50%、EPP 90/95/100、Boost 关闭；不执行 Balance 自动决策。
- 新接入并确认 280W 级适配器后，Eco 自动解除为 Smart Auto，刷新策略恢复 Auto 并立即应用内屏 240 Hz；冷启动已接入可信 280W 时执行相同恢复。
- 安装器不再把刚创建的 `runtime.json` 当作启动成功；只有托盘进入 `Healthy` 且产生首个成功监控心跳后才完成安装，否则在 60 秒内明确失败并保留诊断日志。
- 修复管理员安装态测试误用隔离的 SelfTest 数据目录和旧配置版本断言的问题，并新增运行时健康与成功心跳验证。
- 不修改 OEM 异构核心增减阈值、TGP、风扇、EC 或 DeathAdder V3 Pro HID 控制路径。

## 2.4.5

- 新增离电高耗电进程提示：每 30 秒使用原生 CPU 增量采样，连续 2 次达到单核 15% 且平均放电不低于 14 W 才提示；默认冷却 30 分钟，只提示、不结束任何进程。
- 离电健康主循环从固定 5 秒改为动态 10–15 秒：有明显 CPU/GPU/全屏活动时为 10 秒，低负载、锁屏或手动 Quiet 时为 15 秒；外接供电保持 5 秒，故障退避仍为 10/20/40/60 秒。
- 内屏 Auto 动态刷新率应用或回读验证失败时，自动关闭失败的动态状态并回退到 Eco 60 Hz；外屏继续保持当前分辨率下的最高刷新率。
- 设置页增加离电高 CPU 提示开关，诊断和本地遥测加入候选进程、放电功率、置信度、提示次数与主循环间隔；配置升级为 v13，遥测升级为 v5。
- 不修改 OEM 异构核心增减阈值、TGP、风扇或 EC，也不改变 DeathAdder HID 控制路径。

## 2.4.4

- 内屏新增供电感知 `Auto` 刷新率：电池、USB-C PD 与未确认 AC 使用 Windows 原生 60–240 Hz 动态刷新率，确认 280W 级适配器后固定 240 Hz；外屏继续保持当前分辨率下的最高刷新率。
- 保留手动 Eco 60 Hz 与固定 240 Hz；从电池新接入任意外部供电后自动恢复 `Auto`，避免手动低刷在插电后持续锁定。
- 刷新率自动切换与 HDR、缩放、亮度显式应用解耦，仅在启动、供电变化、显示拓扑变化或用户主动应用时修改显示链路。
- GPU 遥测按场景采用 5/10/20 秒采样周期，并为每个样本增加序号、时间戳和年龄；dGPU 活动检测只累计新样本，避免缓存样本被重复计数。
- 修复 GPU 遥测线程在同一进程停止后无法可靠重启的问题；切换采样周期会立即唤醒线程采用新周期，不再等待旧周期结束。
- 减少后台界面刷新开销：监控循环复用同一电源快照与已验证电源方案，隐藏窗口不再重复更新完整控件或每 5 秒调用 `powercfg`。
- Chrome、Edge、Firefox 等浏览器全屏采用 45% CPU / 20% GPU 和 3 样本专用门槛，降低视频播放、最大化窗口误升 Hyper 的概率；明确应用规则仍保持最高优先级。
- 修复手动 Quiet 在程序冷启动时已经检测到可信 280W 供电却不恢复 Auto，以及 Quiet CPU 曲线提示文本仍显示旧参数的问题。
- 自检日志改写入临时测试目录，避免供电与 dGPU 模拟数据污染正式运行日志；配置升级为 v12，遥测格式升级为 v4。

## 2.4.3

- 未确认 AC 保持 `UnknownAC`，不会用一次低读数自行形成 Quiet → 低 GPU 限值 → PD 的反馈；一次不低于 130W 的读数仍立即确认高功率 AC 并解除手动 Quiet 锁定。
- UI 在 PD 待确认期间区分“保持已验证高功率 AC”和“AC 尚未分类”，不再把所有待确认状态错误显示成保持 Hyper。

- 刷新率按内外屏分流：外屏保持当前分辨率支持的最高刷新率，固定 60/120/240Hz 与 Windows 原生动态刷新只作用于内屏。
- 内屏关闭时不再重复尝试动态刷新或记录失败；外屏仍保持最高刷新率，延迟提示最多每 30 分钟记录一次。

## 2.2.0

- USB-C PD 与电池供电默认 Quiet；电量不低于 50% 时，前台生产力应用在 CPU 不低于 8% 或整机 CPU 达到 35% 后可自动进入 Balance，低于 50% 立即强制回 Quiet。
- PD、电池和无法验证的交流供电均禁止自动进入 Hyper；拔掉高功率适配器时绕过普通防抖，立即退出 Hyper。

- CPU 利用率由 `GetSystemTimes` 原生增量采样，前台应用由 Win32 窗口句柄识别；自动循环不调用 `nvidia-smi`、`Get-Counter` 或 WMI，避免离电时为了判断负载而唤醒独显或增加轮询功耗。

## 2.1.0

- 新增供电分类：利用本机 RTX 5080 的 `enforced.power.limit` 区分原装 280W 适配器（实测 160W）与 100W USB-C PD（实测 70W）。
- Auto 改为 fail-safe：只有 `>=130W` 的可靠证据才进入 Hyper；`<=100W`、读取失败和模糊区间均进入 Quiet。
- 新增 Balance 电源方案：CPU 最大 100%、EPP AC 50/DC 70、Efficient Enabled Boost、适中的 Wi-Fi/PCIe/睡眠策略；不运行 Quiet 的进程、服务和唤醒设备维护。
- Balance 要求电量 `>=50%`；低于 50% 时把持久化选择锁回 Quiet，充电后需手动重新选择。
- 允许在 PD/电池上手动覆盖 Hyper，并增加明确警告；不绕过固件输入功率限制。
- 刷新率改为独立持久化选择：跟随模式、固定 60/120/240Hz、原生动态 60↔120Hz、不管理。
- 新增 Windows DisplayConfig 原生动态刷新实现：活动内屏使用 60Hz 虚拟基础刷新与面板 240Hz 物理 Boost，外屏固定 120Hz；应用后回读验证。现场测试确认驱动在固定 120Hz 时仍保留 240Hz 物理链路，因此不再错误标注为 60↔120Hz。
- 固定刷新率必须在每块活动显示器当前分辨率和色深下精确存在，切换前先全部验证，避免静默选择近似值或部分修改。
- 状态页新增供电类型、NVIDIA 强制/默认/最大功率上限、各显示器可用刷新率及动态刷新状态。
- 新增第三个电源方案的升级、验证、卸载与回滚路径；配置/状态格式升级至 v3。
- 控制面板扩展为四档按钮和独立刷新率选择器，保留 Razer 风格、Per-Monitor V2 DPI 和缩放修复。
- 新增供电边界、50% 阈值、刷新策略、Balance 电源参数及本机动态刷新能力测试。
